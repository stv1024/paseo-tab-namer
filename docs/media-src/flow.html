How Tab Namer works

Everything runs through your own Paseo daemon. The plugin never sees an endpoint or an API key.

1 Read Tabs

Pages through the latest, all, or one chosen Tab and keeps only user / assistant text. Tool logs, reasoning and images stay out.

2 Fit the budget

Counts a conservative bound (UTF-8 bytes + 256). Over budget, each Tab keeps its first ~25% and most recent ~75%, shared fairly.

3 Ask your provider

Starts a short-lived tab-namer session with the provider and model you picked — Claude, Codex, OMP or a custom one.

4 Apply & clean up

Re-checks the current name, applies the new one and archives the helper session. Directory and Git branch are untouched.

Background jobs — closing the popover is fine One job per workspace, three in parallel Refuses to overwrite a name changed meanwhile
