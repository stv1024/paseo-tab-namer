# Tab 重命名卡在上游

2026-10-19 · Paseo 0.11.2 · `@getpaseo/plugin` 0.11.2 · `@getpaseo/client` 0.11.2

> 随笔只记录写作当天的情况，以后会过时。读之前先看 [getpaseo/paseo#7356](https://github.com/getpaseo/paseo/issues/7356) 的状态和新版 SDK。

## 现在能做的

Tab Namer 可以给整个 workspace 改名，用的是 `paseo.workspaces.ref(id).setTitle(title)`。

## 想做但做不了的

我们想给 workspace 里的每个 Tab 也自动改名。Tab 就是 agent，Tab 名称就是 agent 的 `title`。

Paseo 本身已经能改 Tab 名称：

- 协议有 `update_agent_request { agentId, name?, labels? }`。
- `DaemonClient.updateAgent(agentId, { name })` 发送这个请求。
- App 的 Tab 重命名对话框就是调用 `client.updateAgent(id, { name })`。
- CLI 可以用：`paseo agent update <id> --name "新名称"`。

但 plugin 拿不到这个能力。Plugin 的 server 端（`PluginHandlerContext.paseo`）和 client 端（`usePaseo()`）拿到的都是 `PaseoApi`。`PaseoAgentHandle` 只有 `send / run / waitForFinish / commands / archive / detach / refresh / subscribe / respondToPermission / timeline`，没有 `setTitle` 或 `update`。

## 考虑过的方案

1. **向上游提需求**：已选。2026-10-19 提了 [#7356](https://github.com/getpaseo/paseo/issues/7356)，建议给 `PaseoAgentHandle` 加 `setTitle(title)`，写法和 workspace 的一样。
2. **在 plugin server 端调用 CLI**：现在就能用，但要找到 CLI 路径，还要处理 `--home` 和远程 host，所以容易出问题。没有选用。
3. **通过私有字段拿到内部的 `DaemonClient`**：依赖内部实现，Paseo 一升级就可能失效。没有选用。

## 上游支持以后

- 生成名称的部分基本可以复用：`server/source.ts` 已经能按 Tab 读取 timeline，`server/model.ts` 已经能生成名称。
- 需要新增的是：给每个 Tab 生成名称的流程、应用名称的调用，以及 UI 入口（可能是 agent 上下文的 header 按钮或命令中心条目）。
- 记得跳过 Tab Namer 自己临时创建的命名会话（`isGenerator`）。
