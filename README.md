# Paseo AI 重命名

根据会话内容为已有 workspace 重新生成名称。面向本机使用，要求 Paseo 0.11.2 或更新版本。

## 使用

1. 点击 workspace 顶部的 **✨ AI 重命名** 按钮。
2. 选择最近会话、全部会话或指定会话。
3. 可先点 **预览输入**，检查发送内容和预算。
4. 点击 **生成名称**。候选名称可修改，也可再次生成。
5. 点击 **保存名称** 后应用。仅修改显示名称，不修改目录或 Git 分支。

侧栏底部还有 **AI 重命名** 入口。命令中心可搜索 **AI 重命名当前 workspace**、**AI 重命名：根据当前会话**、**AI 重命名设置**。Paseo 目前不支持把插件按钮放入原生右键菜单或重命名对话框。

## 设置

从重命名弹窗的 **设置** 按钮进入。配置由 Paseo 的 host settings 保存，对本机全部 workspace 生效；修改后点击 **保存设置**。

| 设置         | 默认值                     |
| ------------ | -------------------------- |
| 模型连接     | 本机 OMP 的 `custom` 服务 |
| 模型         | `qwen3.5-flash`            |
| 最大输入预算 | 128,000，保守 token 上界   |
| 会话范围     | 最近更新的会话             |
| 内容         | 用户与助手的文字消息       |
| 名称长度     | 最多 48 个字符             |
| 温度         | 0.3                        |
| 请求超时     | 90 秒                      |

还可配置统一命名提示词、自定义 API 基础地址和密钥环境变量名。接口必须兼容 Chat Completions。Qwen 请求关闭 thinking，直接生成名称。

**计数说明：** 不同模型的 tokenizer 不同。本插件用 UTF-8 字节数加 256 作为保守输入预算，包含系统提示词和选取的消息。这个数通常显著高于实际 tokens；128,000 的预算通常容纳几万个实际 tokens，具体取决于文本。界面另用 `gpt-tokenizer` 给出估算，模型返回 usage 时显示实际用量。任意自定义接口仍应自行确保其上下文窗口足够。

短会话的文字完整纳入。超限时每个会话保留开头约 25% 和近期约 75%；多个会话公平分配预算，短会话退还未用空间。很长的会话通过分页读取开头和近期内容，不调用额外模型摘要。预览明确显示截取状态。最多一次处理 100 个会话；极长会话有读取页数上限。

工具日志、推理过程和图片原始内容不进入请求。文字消息中的附件说明若由宿主保存在 `text` 中，会作为文字处理。生成只依据 Paseo 当前可读取的记录，不能恢复宿主已丢弃的历史。

## 本机连接

默认服务端读取 `~/.omp/agent/models.yml` 中 `providers.custom` 的 `baseUrl` 与 `apiKey`，不复制密钥。支持直接密钥及环境变量引用（也可从 OMP 的 `.env` 读取）。不执行密钥配置中的 shell 命令。

自定义接口使用服务进程的环境变量，默认名称 `AI_RENAME_API_KEY`。新增系统环境变量后，需要让 Paseo 服务进程重新加载环境。密钥不会返回界面、打印到日志或保存在此仓库。

所选会话文字将发送到配置的模型接口。插件不自动重命名，不自动发起模型请求。生成与预览采用后台任务，界面轮询状态，避免普通 RPC 的等待时限。每个 workspace 同时只运行一项任务；最多并发三项。完成任务的临时结果约十分钟后从内存移除。

## 开发

```powershell
npm ci
npm run typecheck
npm test
# 会调用当前配置的模型，使用两条合成测试消息
npm run test:smoke
paseo plugin install .
# 修改后
paseo plugin reload ai-rename
```

插件以本地目录安装，需保留 `node_modules`。尚未发布 npm 包或远程仓库。
